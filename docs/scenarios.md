# Six CCAR-F Exam Scenarios

Each exam presents **4 scenarios** drawn from this pool of **6**. Prepare all six.

| Scenario ID | Name | Primary domains |
|-------------|------|-----------------|
| `customer_support` | Customer Support Resolution Agent | D1, D2, D5 |
| `code_generation` | Code Generation with Claude Code | D3, D5 |
| `multi_agent_research` | Multi-Agent Research System | D1, D2, D5 |
| `developer_productivity` | Developer Productivity with Claude | D2, D3, D1 |
| `ci_cd` | Claude Code for Continuous Integration | D3, D4 |
| `structured_extraction` | Structured Data Extraction | D4, D5 |

## Rehearsal prompts (use with Agent mode or self-review)

1. **Customer Support** — How do you gate refund tools behind verified identity?
2. **Code Generation** — When use Plan mode vs Agent mode for a team refactor?
3. **Multi-Agent Research** — How does the coordinator pass context to subagents?
4. **Developer Productivity** — Built-in tools vs MCP for GitHub integration?
5. **CI/CD** — What makes Claude Code safe in non-interactive CI?
6. **Structured Extraction** — Schema validation + retry when nullable fields fail?

See [`flashcards/scenarios/scenario-index.yaml`](flashcards/scenarios/scenario-index.yaml) for structured rehearsal focus per scenario.
